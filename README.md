# DIOS - Difan Integrated Operational System

**Status:** ✅ Backend & Frontend Running | ✅ Login Working | ✅ Template Integrated

A comprehensive Quality Management System (QMS) designed for Indonesian organizations to manage ISO-compliant documentation, operational procedures, and workflow processes.

---

## 🚀 Quick Start

### **Login Credentials**
- **Email:** `admin@dios.com`
- **Password:** `password123`

### **Access URLs**
- **Frontend:** http://localhost:3001
- **Backend API:** http://localhost:8000

### **Start Servers**

**Backend:**
```powershell
cd backend
php artisan serve
```

**Frontend:**
```powershell
cd frontend
npm run dev
```
